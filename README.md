# Sonic Studio

Локальный музыкальный центр для Windows: музыкальная библиотека и плеер, видеоплеер, **сценический вывод на выбранный монитор/проектор**, soundboard, аудиоредактор, эквалайзер, визуализация музыки и управление с телефона через браузер по локальной сети.

Стек: **Electron + TypeScript + Node.js + Express + Web Audio API + Vite + Electron Builder**, хранение настроек в JSON, FFmpeg — опционально (экспорт MP3).

---

## Состав

| Часть | Описание |
|---|---|
| `Sonic Studio.exe` (Electron) | Главное окно приложения + окно **Stage Output** для зрителей |
| Локальный сервер | Запускается автоматически внутри приложения, отдаёт API и веб-интерфейс |
| Веб-интерфейс | `http://127.0.0.1:8765` на компьютере и `http://<IP>:8765` с телефона |

Медиафайлы **не копируются** в папку приложения — воспроизведение идёт напрямую из выбранных вами каталогов. В `%APPDATA%/SonicStudio/` хранятся только настройки, плейлисты, конфигурация soundboard, кэш обложек/миниатюр и журнал.

```
%APPDATA%/SonicStudio/
├── settings/     # settings.json, eq.json
├── playlists/    # музыкальные плейлисты
├── soundboard/   # config.json + files/ (скопированные звуки)
├── cache/        # covers/, thumbs/, exports/
├── logs/         # app.log
└── database/     # music.json, videos.json, история, плейлисты видео
```

## Разделы приложения

- **Главная** — дашборд: плитки быстрого доступа (в приложении), недавние треки/видео, статус сервера; плеер всегда внизу окна.
- **Быстрый доступ на главной** (только в приложении на компьютере) — дашборд: настраиваемая сетка плиток прямо на главном экране, без отдельного раздела и переходов по меню — открыли приложение и всё перед вами. Добавляйте действия плеера (плей/пауза, след./пред., стоп, громкость, повтор, шаффл, стоп-все-звуки), конкретные треки и плейлисты (с обложками), кнопки Soundboard с их цветами, разделы приложения и команды сцены (чёрный экран, вернуть картинку, остановить). Перетаскивание мышью, размеры плиток S/M/L, состав хранится на сервере и переживает перезапуск. Название трека, плей/пауза и громкость — в панели плеера внизу окна. Кнопка плиток — в шапке приложения.
- **Музыка** — импорт файлов и папок, повторное сканирование, поиск по названию/исполнителю/альбому, сортировка, обложки и метаданные (чтение тегов MP3/FLAC/OGG/M4A/AAC/WAV), избранное, история прослушивания, очередь.
- **Плейлисты** — создание/переименование/удаление, состав, порядок (drag&drop и кнопки).
- **Видео** — импорт, карточки с миниатюрами (генерируются автоматически кадрированием), предпросмотр-плеер со всеми управлениями, настройки ролика (громкость, позиции, повтор, **Fade In/Out 0–10 с**, действие после завершения, следующий ролик, экран вывода), плейлисты видео, история просмотра.
- **Soundboard** — наборы кнопок, цвет/значок/громкость/режим (один раз, повтор до остановки, стоп при повторном нажатии), запрет/разрешение наложения, глобальные горячие клавиши, drag&drop, поиск, стоп-все.
- **Аудиоредактор** — волна, выделение, обрезка, громкость, Fade In/Out, прослушивание, экспорт **WAV** (всегда) и **MP3** (при наличии FFmpeg), сохранение под новым именем, добавление в Soundboard. Оригинал не перезаписывается — при совпадении имени запрашивается подтверждение.
- **Эквалайзер** — 10 полос (31 Гц … 16 кГц) через Web Audio API, пресеты Flat/Bass Boost/Treble Boost/Rock/Pop/Classical, пользовательские пресеты, вкл/выкл. Реально влияет на звук в приложении.
- **Визуализация** — частотные столбцы, волновая форма, круговая, компактный спектр, полный экран; работает от `AnalyserNode` реального сигнала; отключается для экономии ресурсов.
- **Сценический вывод** — выбор реального дисплея (данные из `screen.getAllDisplays()`), полный пульт сцены, чёрный экран/возврат, заставка, титры, QR для телефона.
- **Настройки** — медиапапки, порт, доступ по LAN с PIN-авторизацией, значения по умолчанию переходов, crossfade, резервная копия/восстановление, журнал.

## Запуск из исходников

Требуется **Node.js 18+ LTS** (проверено на Node 20/22/24) и Windows 10/11.

```bash
npm install        # установит зависимости и создаст package-lock.json
npm run dev        # режим разработки: Vite (HMR) + Electron
```

Продакшн-сборка и проверка без Electron:

```bash
npm run build      # компиляция main/preload/server (tsc) + renderer (vite)
npm test           # 28 unit/интеграционных тестов
npm run server     # сервер без Electron: http://127.0.0.1:8765
```

## Сборка .exe

```bash
npm run dist             # NSIS-установщик + portable в папку release/
npm run dist:portable    # только portable .exe
```

- Установщик: `release/Sonic Studio Setup 1.0.0.exe`;
- portable: `release/Sonic Studio 1.0.0.exe` (портативная версия хранит данные так же в `%APPDATA%/SonicStudio/`);
- иконка: `assets/icon.png` (генерируется скриптом `node scripts/gen-icon.js`);
- обновление программы **не удаляет** пользовательские данные — они вне папки установки.

Программа не требует Python, ручного запуска Node.js или терминала: сервер стартует вместе с приложением и останавливается при его закрытии.

## Подключение телефона

1. Убедитесь, что телефон и компьютер в одной Wi-Fi-сети.
2. В приложении: **Настройки → Сервер и доступ с других устройств → «Доступ по локальной сети» → Применить**.
3. На компьютере отображается адрес вида `http://192.168.x.x:8765` и **PIN-код**; на странице «Сценический вывод» и в «Настройках» есть QR-код.
4. Откройте адрес в браузере телефона и введите PIN один раз (токен сохраняется).

С телефона доступны: просмотр медиатеки, выбор видео и его запуск, play/pause/стоп/перемотка, громкость, выбор экрана вывода, полноэкранный сценический вывод, чёрный экран и возврат изображения, настройка Fade In/Out, переключение роликов в плейлисте, управление музыкальным плеером и запуск звуков Soundboard.

Синхронизация состояния — через WebSocket; при потере связи в шапке отображается **«Нет соединения»**, а команда считается выполненной только после ответа сервера. Телефон управляет, но не имеет прямого доступа к системным API Windows: выбор дисплеев и перемещение окна вывода выполняет приложение на компьютере по команде сервера. После переподключения телефона ничего не запускается автоматически.

## Выбор сценического экрана

1. Подключите второй монитор/проектор (HDMI-проектор, распознанный Windows, появится в списке как дисплей).
2. Раздел **«Сценический вывод»** → карточка дисплея (номер, разрешение, положение, статус). Выбранный дисплей запоминается как экран по умолчанию.
3. Выберите видео → **«Вывести и играть»**: откроется окно **Stage Output** только с контентом (без интерфейса) и переместится на выбранный экран в полный экран.
4. Кнопки пульта: запуск/пауза/продолжить/стоп, перемотка, предыдущий/следующий, полный экран, **чёрный экран** (контент скрыт, окно и сервер живы), **вернуть изображение**, Fade In/Out, заставка, титры, обновить дисплеи.
5. Если выбранный дисплей отключён: при запуске появится запрос подтверждения на вывод на основной экран; если монитор пропал во время показа — вывод безопасно вернётся на основной экран с уведомлением. На другой экран без вашего подтверждения видео не переносится.

## Настройка затухания видео

- Для каждого ролика: карточка → **иконка настроек** → Fade In / Fade Out (0–10 с; 0 = мгновенно; независимо друг от друга), громкость, начальная/конечная позиция, повтор, действие после завершения, поведение при остановке, следующий ролик, экран вывода. Настройки сохраняются для конкретного ролика.
- Значения по умолчанию для новых роликов: **Настройки → Переходы, звук и заставка**.
- Переходы выполняются **реально** в окне сцены: картинка появляется из/уходит в чёрный, громкость плавно нарастает/затухает. Если воспроизведение прервано во время перехода — переход корректно завершается или мгновенно прекращается (кнопка «Остановить»).
- **Crossfade** (два одновременно декодируемых источника) включается отдельно в настройках и по умолчанию выключен — это дополнительная нагрузка.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Space` | Play/Pause (если фокус не в поле ввода) |
| `Ctrl + →` / `Ctrl + ←` | Следующий / предыдущий трек |
| `Ctrl + ↑` / `Ctrl + ↓` | Громче / тише |
| `Escape` | Закрыть модальное окно / выйти из полного экрана |
| Клавиша кнопки Soundboard | Срабатывает глобально (регистрируется через `globalShortcut`, снимается при выходе); занятые сочетания сообщаются уведомлением |

## Быстрый доступ на главной

1. Откройте приложение — главный экран и есть дашборд. Если плитки выключены, на главной появится карточка «Включить» (или «Настройки» → «Быстрый доступ на главной»). Кнопка плиток в шапке всегда возвращает на дашборд из любого раздела.
2. «Добавить» — выберите вкладку: Действия / Треки / Плейлисты / Звуки / Разделы — и щёлкните нужный элемент.
3. «Редактировать» — перетаскивайте плитки мышью, кнопкой S/M/L меняйте размер (S 1×1, M 2×1, L 2×2), крестик убирает плитку.
4. Нажимайте плитки — трек, плейлист, звук или команда выполняются сразу, без перехода из окна: название играющего трека, плей/пауза и громкость видны в панели плеера внизу окна.
5. Состав и порядок сохраняются автоматически (settings/quick.json), попадают в резервную копию и переживают обновление приложения.

## Безопасность

Electron: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`, безопасный preload (`contextBridge`), IPC только по явным каналам с проверкой аргументов, CSP-заголовки.

Сервер: слушает только `127.0.0.1`; доступ по LAN включается вручную и защищён PIN → токен (защита от перебора PIN). Медиа отдаётся только через контролируемый API с проверкой разрешённых каталогов (защита от `../`, абсолютных путей, null-байт). Произвольный доступ к файловой системе и системным командам отсутствует; FFmpeg вызывается с фиксированными аргументами (без shell). Автоматического проброса в интернет нет.

## FFmpeg (опционально)

Нужен только для экспорта MP3 в аудиоредакторе. Варианты: положите `ffmpeg.exe` рядом с приложением (папка `resources/ffmpeg/`) или в `PATH`, либо раскомментируйте `extraResources` в `electron-builder.yml`, положив его в `ffmpeg-bin/`. Экспорт WAV работает всегда (собственный энкодер).

## Известные ограничения

- Декодирование видео выполняет Chromium: MP4/WebM воспроизводятся надёжно; MKV/AVI/MOV могут не открыться — приложение предупреждает в карточке и показывает понятное сообщение.
- Crossfade требует одновременного декодирования двух видеопотоков — включайте осознанно.
- Глобальные сочетания Soundboard перехватываются системно во всех приложениях; занятые Windows сочетания зарегистрировать нельзя (приложение сообщит об этом).
- Генерация миниатюр видео выполняется браузером последовательно в фоне; для больших библиотек обложки появляются постепенно.
- Экспорт MP3 доступен только при наличии FFmpeg; WAV — всегда.
- Порт по умолчанию 8765; при занятости автоматически выбирается следующий свободный (8766…8785).
- QR-код и LAN-адрес отображаются, когда в системе есть IPv4-адрес, отличный от loopback.
